Setup: import `schema.sql` in phpMyAdmin and place this folder in `htdocs`. For local XAMPP access on `localhost` and CLI seeding, `includes/init.php` supplies development defaults (`127.0.0.1`, `greek_recipe_hub`, `root`, blank password) only when the matching variables are unset. For production, configure `DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASS`, and `APP_ENV=production` in the Apache environment outside `htdocs`; use a dedicated database account with a non-empty password. Then open `/MidtermMilestoneProj-Ancog/register.php`.
