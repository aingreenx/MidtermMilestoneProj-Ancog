Setup: import `schema.sql` in phpMyAdmin and place this folder in `htdocs`. Configure `DB_HOST`, `DB_NAME`, `DB_USER`, and `DB_PASS` in the Apache environment (for XAMPP, use an Apache config file outside `htdocs`); use a dedicated database account with only the privileges this application needs, not `root`. Set `APP_ENV=production` when serving over HTTPS so session cookies use the Secure flag. Then open `/MidtermMilestoneProj-Ancog/register.php`.
